FOUNDER COMMAND CENTER
======================

Package contents
----------------
1. Founder_Command_Center.html
   - Standalone browser app.
   - Open the HTML file in Chrome, Safari, or Edge.
   - Your app data is saved in that browser's local storage.
   - Use the app's JSON backup/export feature regularly.
   - Import a JSON backup to restore data in the same or another browser.

2. Founder_Command_Center_Sheets_Template.xlsx
   - Companion spreadsheet template for structured records and manual tracking.

Important
---------
- No server or installation is required for the standalone HTML app.
- Browser data is stored locally. Clearing browser data may remove it, so keep JSON backups.
- The spreadsheet is a companion template; it is not automatically synchronized with the HTML app.
- This package intentionally excludes all API keys, passwords, and service-account credentials.
